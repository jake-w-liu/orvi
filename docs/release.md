# Lux Release Runbook

This runbook tracks the release paths that are already wired in this repository.

## VS Code Marketplace

The first VS Code Marketplace release is public:

- Extension: `jake-w-liu.lux-language`
- Version: `0.1.0`
- Marketplace URL: <https://marketplace.visualstudio.com/items?itemName=jake-w-liu.lux-language>
- Install command: `ext install jake-w-liu.lux-language`

### Local package check

```sh
npm --prefix vscode/lux ci
npm run vscode:package
```

The generated `.vsix` is ignored by git.

### Automated publish

The workflow at `.github/workflows/publish-vscode.yml` is manual-only through
`workflow_dispatch`. It packages the extension, stores the VSIX as a workflow
artifact, verifies the Marketplace token, then publishes that exact VSIX.

Required repository secret:

- `VSCE_PAT`: a Visual Studio Marketplace/Azure DevOps personal access token
  that has publish rights for publisher `jake-w-liu`.

Before publishing, the workflow runs:

```sh
npx vsce verify-pat jake-w-liu --pat "$VSCE_PAT"
```

If the optional `version` workflow input is set, the workflow packages that
version with `--no-git-tag-version`; commit the matching version bump separately
when cutting a durable release.

## GitHub Pages

GitHub Pages is enabled for this repository with `build_type: workflow`.

The Pages workflow at `.github/workflows/deploy-pages.yml` builds:

- `/playground/`
- `/rendered/` HTML previews for repository `.lux` files
- `/schemas/`
- `/version.json`

The generated Pages artifact includes `CNAME` with:

```text
lux-lang.dev
```

The default Pages URL is:

```text
https://jake-w-liu.github.io/lux/
```

GitHub still needs the Pages custom domain configured in repository settings or
through the Pages API before `lux-lang.dev` can serve this deployment. DNS for
`lux-lang.dev` must then point at GitHub Pages; as of this repo state, public
DNS resolves through Cloudflare to an existing site, not this Pages deployment.

## Native GitHub `.lux` Rendering

GitHub does not provide arbitrary repository-native renderers for new file
extensions. Until GitHub platform support exists, this repo ships the practical
fallback: GitHub Pages previews generated by `scripts/build-site.mjs`.
